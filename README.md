# clean-takes — чистая нарезка дублей из сырого видео

Снял себя одним длинным дублем: переговаривал фразы, спотыкался, мычал, делал паузы. `clean-takes` сам находит, какие фразы ты сказал чисто, вырезает только их и склеивает ролик. Опционально чистит звук от шума нейросетью.

**EN:** Raw talking-head recording with retakes → clean cut. Whisper word timestamps find repeated phrases (the last full attempt wins), restarts inside a phrase, lone fillers («а», «эм») and long pauses; cuts are placed on the audio envelope, frame-exact, with click-free audio joins. Optional DeepFilterNet 3 noise removal. CPU only, no API keys.

## Что делает

1. **Распознаёт речь** с точным временем каждого слова (faster-whisper, локально).
2. **Делит на фразы** по точкам и паузам.
3. **Находит дубли.** Если одна из следующих фраз начинается так же или повторяет большую часть текущей, текущая считается неудачным дублем. Остаётся **последняя** попытка. Пример: «Короче, это не приложение для изучения языков, это зель…» → «Короче, это не приложение для языков, это абьюзер с зелёными перьями» — останется вторая.
4. **Ловит перезапуск внутри фразы:** «и вот обещанная мерзость и вот обещанная мразь» → остаётся «и вот обещанная мразь».
5. **Убирает мычание:** фразы из одних «э / мм / а», короткие звуки на краях фраз, отрезанные паузой, паузы длиннее 0,3 с.
6. **Режет по громкости голоса,** а не по примерным временам Whisper, чтобы не съесть первую и последнюю букву. Куски выравнивает по кадрам, звук склеивает с плавными стыками в 10 мс (без щелчков), выравнивает громкость до −14 LUFS.
7. **Проверяет себя:** заново распознаёт готовый ролик и кладёт текст в отчёт.

## Установка

Нужны Python 3.10+ и ffmpeg.

```bash
git clone https://github.com/levizdev/clean-takes && cd clean-takes
bash setup.sh              # нарезка
bash setup.sh --denoise    # + шумодав (нужен Python 3.10/3.11 или uv)
```

Первый запуск скачает модель Whisper small (~500 МБ) в `~/.cache/huggingface` (меняется переменной `HF_HOME`).

## Запуск

```bash
# 1) план без рендера: какие фразы останутся и почему
.venv/bin/python clean_takes.py raw.mp4 out/cut.mp4 --plan-only

# 2) рендер
.venv/bin/python clean_takes.py raw.mp4 out/cut.mp4

# с чистым звуком
.venv-denoise/bin/python denoise.py raw.mp4 out/clean.wav
.venv/bin/python clean_takes.py raw.mp4 out/cut.mp4 --audio out/clean.wav
```

Рядом с результатом появятся:
- `cut_report.md` — каждая фраза с решением: ✅ оставлена / ❌ неудачный дубль / оговорка / мычание. В конце — что слышно в готовом ролике.
- `cut_plan.json` — поменяй `"keep"` у любой фразы и перерендерь: `--plan out/cut_plan.json`.
- `cut_edl.json` — итоговые куски в секундах исходника.

| Флаг | Что делает |
|---|---|
| `--lang ru` | язык (`auto` — определить) |
| `--model small` | `medium` / `large-v3` — точнее, медленнее |
| `--prompt "Claude, Duolingo"` | подсказка Whisper: имена, бренды, сленг |
| `--pause 0.3` | вырезать паузы длиннее, с |
| `--window 20` | как далеко вперёд искать повтор фразы, с |
| `--size 1080x1920` | размер кадра (по умолчанию 1080 по короткой стороне) |
| `--fps 30`, `--crf 16`, `--jobs N` | кадры, качество, параллельные куски |
| `--loudnorm -14` | громкость LUFS (`nan` — не трогать) |
| `--audio file.wav` | взять звук из файла (например, после шумодава) |

### Шумодав (`denoise.py`)

DeepFilterNet 3 + мягкая обработка голоса: срез низов и верхнего шипа, де-эссер, компрессор, +2,5 дБ разборчивости, гейт в паузах, −16 LUFS.

- `--atten 32` (по умолчанию) — насколько сильно давить шум, дБ. Без ограничения нейросеть вместе с шумом съедает слова, если микрофон далеко (камера в 1–2 м у бассейна, на улице). С петличкой можно `--atten 100`.
- Файл обрабатывается кусками по 8 с с перекрытием: на длинных файлах DeepFilterNet иногда «схлопывается» в тишину после ~25 с.

## Скорость

На 4 ядрах CPU:
- распознавание (Whisper small): ~1 минута на минуту записи;
- 4K HEVC с телефона/DJI: декодирование ~4 с процессора на 1 с готового видео 1080p;
- шумодав: ~5 с на минуту звука.

Для быстрого просмотра: `--size 540x960 --crf 28`.

## Ограничения

- Поиск дублей работает по словам Whisper. Если Whisper «пригладил» запинку (записал слово так, как ты хотел его сказать), она может остаться. Посмотри результат и, если где-то цепляет ухо, убери фразу в `_plan.json`.
- Фразы со средней уверенностью распознавания ниже 0,35 помечаются в отчёте ⚠️ — их стоит проверить на слух.
- Однословная фраза, за которой идёт предложение с того же слова, считается фальстартом и вырезается.
- Звук из кадров, где камера пишет сама себя (без петлички), шумодав очистит частично: при сильном подавлении страдают окончания слов.
